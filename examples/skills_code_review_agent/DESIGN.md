# 设计说明

该示例把自动代码审查拆成确定性核心和 Skill 集成两层：核心只处理 diff、脱敏、规则、去重、持久化和报告，保证 dry-run 可复现；Skill 层只暴露受控脚本，通过 `SkillToolSet` 与 `skill_run` 在容器工作区执行，local 仅作为显式开发回退。sandbox 之前统一经过 Filter 策略，拒绝危险命令、敏感路径、越界输出和泄露型环境变量，网络、安装包、未知可执行文件与容器回退进入人工复核。遥测记录输入规模、规则命中、低置信丢弃、拦截、sandbox 状态和脱敏数量。数据库按任务、输入、sandbox、finding、filter、telemetry、report 分表保存，且只写入脱敏 diff。finding 用文件、行号、类别与规范标题生成稳定键，再按同位置同类别合并来源，降低噪声。安全边界是：秘密先脱敏再持久化，命令先过滤再执行，报告只输出可复核证据与修复建议。
